# MeetFlow 安全边界

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

- 账号使用BCrypt12；密码至少12位含大写、小写、数字且UTF-8不超过72字节。初始密码独立生成，无统一演示密码。
- 登录会话30分钟，Cookie HttpOnly、SameSite=Strict，HTTPS部署应启用Secure。CSRF令牌仅在页面内存，凭据不写浏览器存储。
- 登录错误按IP＋账号限制为5分钟8次；进程内限速不适用于分布式防护，网关仍应配置访问策略。
- 账号停用和密码变化使旧会话失效；每次操作从数据库读取当前角色。导航隐藏不替代接口权限。
- 申请人不能自审，管理员不能凭身份绕过指定审批人。维护不能覆盖预约。资源行锁、版本、命令摘要共同保护状态和并发。
- 预约历史、维护取消和提交快照保留；被引用目录和最后一个启用全范围管理员不能随意删除。
- 数据查询绑定参数，排序有限枚举；界面使用Vue文本转义。JSON导出没有品牌推广、密码或哈希。错误响应不输出异常栈。
- 同源代理限制来源，Nginx配置CSP、点击劫持和类型嗅探防护。默认仅本机端口；未包含网关、高可用、SSO、多租户和外部通知。
- 当前测试未包含负载、专业渗透、外网攻防和灾备认证。发布前扫描源码和图片，真实 `.env` 及验收密码文件不入库。
